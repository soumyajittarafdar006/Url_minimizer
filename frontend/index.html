About TinyURL

Academic Data Structures and Algorithms Project

“TinyURL is a Data Structures and Algorithms project implemented in C. It demonstrates URL shortening using hash tables, separate chaining, singly linked lists and Base-62 encoding. The application also supports URL searching, deletion, click tracking, file persistence and collision analysis.”

1 Hash Table Architecture

Utilizes a fixed prime array of TABLE_SIZE = 101 bucket heads. Prime table sizes prevent arithmetic clustering when modulo arithmetic is applied to uniform hash keys.

2 Polynomial Rolling Hash

Implements Horner's rule with prime multiplier 31: hash = (hash * 31 + char) % 101. Provides uniform distribution across ASCII alphanumeric characters in O(k) time.

3 Separate Chaining Collision Handling

When two distinct short codes map to the same bucket index, they are appended to a singly linked list (URLRecord nodes) pointed to by the bucket index. Deletion and searches traverse only that specific chain.

4 Base-62 Code Generation

Short codes are generated deterministically using Base-62 encoding over a monotonic counter using character set [0-9A-Za-z], yielding ultra-compact lookup keys.

5 File Persistence

All URL records, click counts, and monotonic sequence counters are persisted to data/urls.dat with atomic temporary file writes and safe reloading across restarts.

6 Time & Space Complexity

Lookup & Deletion: O(1 + α) average, where α = n / m is the load factor.
Shortening: O(1) amortized.
URL Reverse Search: O(m + n) linear table scan.
